How I work

From brief to handoff
1

Read the business first

Prices, tiers, payment provider limits, legal copy. I find out what can't change before I draw anything.

2

Map every state

Empty, loading, declined, timed out, paid. Edge cases get designed up front, not discovered in QA.

3

Prototype in code

I build clickable HTML and React prototypes, so stakeholders judge real motion and timing instead of static frames.

4

Hand off a system

Tokens for color, type, radii and spacing, plus component states, so developers build exactly what was approved.
